# 鹿児島 防災ナビ v3

鹿児島市向けのパーソナル防災PWA。GitHub Pages で配信し、気象データは GitHub Actions が
15分おきに取得して `data/*.json` にコミットする構成です。

## ファイル構成

```
index.html                       アプリ本体（CSS・JSすべて同梱）
sw.js                            Service Worker（本体=cache first / data=network first）
manifest.json                    PWAマニフェスト
data/now.json                    天気・風・警報・噴火警戒レベル・雨雲タイルの時刻
data/rain.json                   日別降水量と 今日/7日/30日/90日 の累計
data/transit.json                公共交通のリンクと状態
data/places.json                 避難施設（座標は要確認・手で直せます）
scripts/fetch_data.py            データ取得スクリプト
.github/workflows/update-data.yml  定期実行ワークフロー
```

## 導入手順

1. リポジトリのルートに上のファイルを置く（既存の `index.html` は差し替え）。
2. Settings → Actions → General → Workflow permissions を
   **Read and write permissions** にする。これがないと Actions がコミットできません。
3. Actions タブから `update-data` を手動実行し、`data/*.json` が更新されるか確認する。
   初回は「daily = true」で実行すると日別降水量も入ります。
4. `icon-192.png` と `icon-512.png` をルートに置く（未配置だとホーム画面追加の見栄えが落ちます）。
5. Googleマップを使う場合は、アプリの「設定 → Googleマップ」に Embed API のキーを入れる。

## Googleマップについて

- **Maps Embed API** を使っています。無料で回数制限はありませんが、Google Cloud 側で
  請求先アカウントの登録は必要です。キーには HTTP リファラー制限
  （`zen-chick.github.io/*`）を必ずかけてください。
- 航空写真は出ないように `maptype=roadmap` を固定しています。
- Googleの「保存済み（スター）」はAPIが公開されていないため読み書きできません。
  代わりに、Googleマップの共有リンクを貼ると座標を取り込む仕組みにしています。
  スマホのGoogleマップで「共有 → リンクをコピー」→ アプリの登録画面に貼り付け → 読み取り。
- ルート検索は日本だけ公共交通モードがAPI提供されていません。
  車・徒歩・自転車はアプリ内に埋め込み表示、乗換は Googleマップアプリを開く形にしています。
- Googleのタイルは規約上オフライン保存できないため、地図タブはオンライン専用です。
  オフラインで使う地図は国土地理院タイルを使う「雨量・台風」「土砂・火山」タブ側にあります。

## オフライン保存の仕組み

- アプリ本体と `data/*.json` は Service Worker がキャッシュします。
- 雨雲レーダーとハザードマップのタイルは **IndexedDB** に保存します。
  各タブの「この範囲を保存」を押すと、表示中の範囲（現在のズーム＋1段階）を最大600枚まで
  取り込みます。圏外になると保存済みタイルを自動で表示します。
- 保存容量は 設定 → オフライン保存 で確認・削除できます。

## リスク計算の中身

`index.html` の `riskParts()` が計算しています。点数はすべて調整可能です。

| 項目 | 配点 |
|---|---|
| 1時間雨量 | 最大30点（1mm=1点） |
| 3時間雨量 | 最大25点（100mmで満点） |
| 24時間雨量 | 最大25点（200mmで満点） |
| 先行7日雨量 | 最大10点（200mmで満点） |
| 大雨注意報 | +5 |
| 大雨・洪水警報 | +15 |
| 土砂災害（警報の付加情報） | +30 |
| 記録的短時間大雨情報 | +20 |
| 大雨特別警報 | +40 |
| 土砂災害警戒区域のスポット | ×1.15 |
| 浸水想定区域のスポット | ×1.15 |

0〜100点を 平常／注意／警戒／危険／災害切迫 の5段階で表示します。
**これはアプリ独自の目安です。** 実際の避難判断は鹿児島市の避難情報と
気象庁キキクルを優先する前提で、画面にもその旨を出しています。

## 動かしてみて確認が必要なところ

作った時点で外部サービスに繋げない環境だったため、以下は実際に動かして確認してください。

- **過去の降水量**（`fetch_data.py` の `ETRN_PREC=88` / `ETRN_BLOCK=47827`）。
  気象庁「過去の気象データ」のHTML表を読んでいるので、表の列構成が変わると
  `days` が空になります。その場合は `DailyTableParser` の列インデックス（現在は3列目）を直してください。
- **ハザードタイルのURL**（`CFG.hazard`）。ハザードマップポータルのレイヤ名が変わると
  404 になります。ポータルで対象レイヤを表示し、開発者ツールの Network タブから
  実際のタイルURLをコピーして差し替えるのが確実です。
- **噴火警戒レベル**の取得先。取れない場合は前回値を保持するので、
  取得に失敗し続けるようなら `data/now.json` の `volcano` を手で直すか、
  `fetch_volcano()` の取得先を変更してください。
- **警報コードの対応表**（`WARNING_NAMES`）。見慣れない表記が出たら追加してください。
- **避難施設の座標**（`data/places.json`）。おおよその値です。
  鹿児島市の指定避難所一覧で確認して置き換えてください。

## 公共交通の遅延について

遅延情報を無料で提供している公開APIがありません（かつての「鉄道遅延情報のjson」は
2022年5月に無料開放を終了、鹿児島市営バスのGTFSは静的データのみで
リアルタイム配信なし）。そのため各社の公式ページへのリンク表示が既定です。

JR九州のページから簡易判定を試したい場合は、ワークフローの環境変数
`BOUSAI_PROBE_TRANSIT` を `1` にしてください。ページ構造に依存する雑な判定なので、
外したときは `unknown`（「公式を確認」表示）に落ちるようにしてあります。

## 削除した機能

季節別リスクカレンダー、土砂災害統計、降灰チェック、今日のチェックリストを外しました。
土砂災害の前兆サインも指示どおり外していますが、命に直結する内容なので、
大雨警報や土砂災害警戒情報が出ているときだけ表示する形で戻すこともできます。
